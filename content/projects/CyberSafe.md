## Overview
Developing an offline 3D educational RPG focusing on gamified cybersecurity concepts. The game is highly optimized for mobile devices.

## Key Features
* **Mobile-Optimized Mechanics**: Engineered interactive UI elements, including a responsive password strength analyzer custom-built for mobile keyboard overlays.
* **Performance Optimization**: Executed extensive mobile performance optimizations utilizing static batching, mesh compression, and GPU instancing to maximize framerates.
