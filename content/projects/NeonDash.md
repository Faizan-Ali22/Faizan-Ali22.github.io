## Overview
Neon Dash is a high-speed 3D platformer endless runner developed in Unreal Engine 5.7. Players control a futuristic runner traversing floating neon tracks high above a cyberpunk metropolis, dodging dynamic vertical obstacles and collecting energy cores to maintain speed.

## Key Features
* **Dynamic Procedural Generation**: Implemented a highly optimized level spawner that procedurally generates tracks, obstacles, and power-ups, ensuring a unique path for every run while maintaining constant memory usage.
* **Physics-Based Fluid Movement**: Programmed custom character movement physics using C++ to achieve tight, responsive controls including wall-running, sliding, and double-jumping.
* **Visual Effects & Materials**: Authored stylized neon materials and particle effects in Unreal Engine to create a vibrant cyberpunk aesthetic with high-speed motion blur and global illumination.
* **Unreal Engine 5.7 Architecture**: Utilized a hybrid C++ and Blueprint system to balance performance and rapid prototyping.
