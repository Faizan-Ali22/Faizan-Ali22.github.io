## Overview
Built a first-person sci-fi shooter in Unity for WebGL delivery, focusing on playable browser performance, maintainable C# code, and a clean player experience across desktop and mobile-sized viewports.

## Technical Highlights
* **Unity WebGL Delivery**: Developed and optimized browser-based gameplay for HTML5/WebGL deployment.
* **Gameplay Systems**: Implemented combat, movement, UI flows, animations, and feedback loops to support engaging moment-to-moment play.
* **Performance Optimization**: Tuned memory usage, loading behavior, and responsiveness to keep the experience stable in the browser.
* **Production Readiness**: Used Git for version control, debugging, and iterative improvement during development.
