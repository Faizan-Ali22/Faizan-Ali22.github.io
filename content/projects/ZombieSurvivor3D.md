## Overview
A post-apocalyptic 3D action-survival game with wave-based combat and resource management.

## Key Features
* **Asset Creation**: Created all 3D models, environments, and animations from scratch in Blender using PBR texturing workflows tailored for Unity integration.
* **AI & Gameplay**: Engineered enemy AI behavior using finite state machines and dynamic pathfinding. logic. Delivered a complete gameplay loop including weapons, health, scoring, and game state management.
