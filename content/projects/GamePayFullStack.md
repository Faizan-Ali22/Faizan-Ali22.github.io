## Overview
Full-stack implementation of the GamePay gaming payment platform concept. Built with React on the front end and Node.js with MySQL on the back end, turning the original UI/UX design into a fully functional web application.

## Key Features
* **React Front End**: Component-based UI built with React for a responsive, dynamic user experience.
* **Node.js Back End**: RESTful API server handling authentication, transactions, and data management.
* **MySQL Database**: Relational database powering user accounts, payment records, and game catalogs.
* **Full-Stack Architecture**: End-to-end implementation from client to server to database.
